## 目标与范围
1. **FastAPI 与路由**：
   - 统一错误响应结构（code, message, detail, timestamp）
   - 待确认信号 API、确认下单 API（POST + 一次性令牌二次确认，GET 绝不产生交易）、策略管理与审批 API、紧急开关 API（停止开仓、全部平仓、人工恢复）
   - WebSocket 实时推送与心跳
2. **鉴权与安全**：
   - 用户名密码 + RFC 6238 标准强制 TOTP 双因素认证
   - 登录失败 5 次锁定 15 分钟防暴力破解
   - JWT 会话与权限中间件
   - 一次性确认链接令牌签名（HMAC-SHA256）、15 分钟 TTL、防重放、防 CSRF
3. **邮件通知（`notify/`）**：
   - 邮件作为唯一外部通知渠道（SMTP，支持 TLS/SSL）
   - HTML 深色科技质感模板（OLED 纯黑、翡翠绿、霓虹红、移动端自适应）
   - 标准标题前缀（`[DQ][模拟盘][开仓]`、`[DQ][实盘][待确认]`、`[DQ][告警]` 等）
   - 可靠性保证：失败重试 3 次，仍失败写入 `notify_outbox` 待补发
   - 限流与去重：每小时最多 30 封，同类告警去重，选币结果合并摘要
4. **审计日志与脱敏**：
   - 敏感操作（登录、确认下单、修改策略参数、AI 提案批准、紧急停止开仓、全部平仓）写入 `AuditLogModel`
   - API Key 仅保留后 4 位，密码、Token、Secret 全局自动脱敏
