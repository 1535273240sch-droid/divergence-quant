# M13 部署运维 任务说明

## 模块信息
- 模块编号：M13
- 模块名称：部署、监控、备份与灾难恢复
- 对应计划书：第 10 章、第 11 章、第 12 章、第 13 章 T10.1、T10.2 及决议 D39
- 负责范围：
  - `docker-compose.yml` 容器编排
  - `deploy/` 目录（Nginx、Prometheus、Grafana、logrotate、PostgreSQL/TimescaleDB、systemd、README.md）
  - `scripts/` 目录（healthcheck.sh, deploy.sh, backup.sh, restore.sh）
  - `tests/unit/test_m13_deploy.py`

## 交付目标与指标
1. 云服务器一键从零部署（按 `deploy/README.md` 指引）。
2. 全站容器化隔离运行，无明文硬编码密钥。
3. Nginx 强制 HTTPS 反向代理，支持 WebSocket 与 API 安全限流。
4. Prometheus + Grafana 可观测性全覆盖（7 大关键业务与系统告警）。
5. 每日备份加密存储并保留 30 天，RPO ≤ 24 小时。
6. 灾备恢复流程完备，RTO ≤ 30 分钟，恢复后强制停开仓，必须人工放行。
7. 安全发布流程遵循“停开仓 → 更新 → 对账 → 人工放行”铁律。
