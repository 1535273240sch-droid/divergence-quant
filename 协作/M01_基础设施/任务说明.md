# M01 基础设施、配置与数据库

## 规格来源

- `项目执行计划书.md` §3.3、§7、§8、§13.2 的 T1.1～T1.3
- `协作/00_总控/接口契约.md`

## 本模块负责

- YAML 配置加载和环境变量覆盖。
- demo/live/backtest 模式校验。
- live 模式的 `LIVE_TRADING_CONFIRM=YES` 安全门禁。
- SQLAlchemy 异步数据库引擎和公共元数据。
- Alembic 初始迁移。
- Redis 异步客户端创建和健康检查边界。

## 本模块不负责

- OKX API 和行情采集。
- 具体策略、指标、风控计算和订单执行逻辑。
- 真实数据库部署和 Docker Compose 运维。
