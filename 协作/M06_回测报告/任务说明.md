# M06 回测引擎与绩效报告

## 规格来源

- `项目执行计划书.md` §5.9、T5.1～T5.4、§7 `backtest_runs`、§17.6.7。
- `AI模块开发分工与整合方案.md` M06。
- `协作/00_总控/接口契约.md` v0.1。

## 本模块负责

- 事件驱动、按 K 线逐根推进的回测内核。
- 信号收盘产生、下一根执行周期开盘成交的撮合规则。
- 手续费、滑点、永续资金费率和保守成交规则。
- 多币种共享账户的组合回测，以及向 M08 风控注入完整组合上下文。
- 训练窗口 / 样本外测试窗口、Walk-Forward 滚动验证。
- 参数网格扫描与二维参数热力图。
- S1/S2/S3 或 SMA200/EMA200 变体的逐策略对比报告能力。
- HTML 资金曲线、回撤曲线、月度收益、逐笔交易明细和偏差警示。

## 本模块不负责

- 指标、趋势分类、背离检测、选币和策略信号的具体实现（M03/M04/M05/M07）。
- 风控规则、仓位计算和熔断逻辑（M08）。
- 交易所连接、历史补数和行情质量修复（M02）。
- 实盘下单、OMS 和对账（M09）。
- FastAPI、通知、Web 页面和逐笔 K 线截图展示（M11/M12）。
- 修改公共契约、`pyproject.toml`、`config/config.yaml` 或其他模块目录。

## 依赖与消费者

- 依赖：M01 的 Python 工程基线；M02 的已确认 K 线；M03/M04/M05 的特征输出；
  M07 的策略 `Signal`；M08 的 `RiskDecision`。
- 消费方：M05/M10 的自动回测门禁、M11 的回测任务与报告接口、M12 的回测页面。
- 当前 M03/M04/M05/M07/M08 尚未完成，M06 通过注入式 Protocol 与测试桩验证，
  不复制这些模块的业务逻辑。

## 验收口径

1. 回测不包含“回测专用信号逻辑”，策略通过 `on_bar(context)` 返回公共 `Signal`。
2. 同根 K 线同时触发止损与止盈时按止损处理。
3. 能分别输出每个策略的报告，不能用组合收益掩盖单一策略失效。
4. 输出可复现元数据：配置哈希、行情指纹、引擎/成本模型版本、随机种子。
5. 所有金额、价格、数量使用 `Decimal`，所有时间戳使用 UTC 毫秒。
